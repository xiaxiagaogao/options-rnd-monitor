# 止盈止损曲线（exit curves）— 设计

> 日期：2026-09-25
> 状态：设计定稿（与用户逐条讨论确认），待实现
> 相关：`docs/superpowers/specs/2026-07-28-binance-entry-anchor-design.md`（币安开仓点）、`holdings-sync-framework.md`（持仓同步 SSOT）、`rnd-dashboard-spec.md` §6（冻结线 / 换月重钉纪律）

## 1. 目标

新增独立页面「止盈止损」。对每个有 RND 覆盖的币安持仓，画**有且仅有两条**「价位 → 概率」曲线，帮用户在定止盈、止损价位时看清其中的取舍：价位越远，锁定的越多，但被触及的概率越低。

**系统不生成目标价，也不标「最优点」**，只说明每个价位在分布里意味着什么。这和研究助手的纪律一致：目标由用户定，系统负责告诉用户那个价位意味着什么。

## 2. 两条曲线的定义

| | 曲线一：成本价位 | 曲线二：当日价位 |
|---|---|---|
| 用哪天的分布 | **本周期第一天**的 pinned 分布，冻结到本周期到期不变。若入场日就在本周期内，则用入场日（即 `holdings_sync.entry_dates()` 的 `rnd_date`） | 最新数据日的 pinned 分布，每天更新 |
| 管到哪天 | 当前 pinned 到期日（下一个到期） | 同左 |
| 盈亏锚点 | **成本价** = `binance_entry.entry_price`（币安 PositionRisk 口径，见 `72e37b1`）。用户加减仓后自动跟着变 | 最新数据日的 `underlying_close`（界面上注明「{日期} 美股收盘」） |
| 「锁定多少」 | `qty × (K − 成本价)` | `qty × (K − 当日收盘)` |

### 2.1 「本周期第一天」

即当前 pinned 到期日成为 pinned 的第一个交易日（可以用 `rnd_indicators.roll` 判定，也可以取「该 expiry 最早的 pinned 日期」），且不早于持仓的 `open_date`。这和冻结线已有的换月重钉规则（`rnd/journal.py::roll_repin_check`）等价：周期内冻结，换月时重钉一次。

**为什么不冻结在入场日**：入场日分布覆盖的时间窗早就过去了。现有老仓位都是 3–6 次换月之前开的，冻结在入场日的曲线描述的是一段已经结束的时间。

### 2.2 已知的不一致（本卡不处理）

标的页「持仓 · 冻结线」卡里的 `binance_entry.frozen` 目前按**入场日**取，不随换月重钉（`server/queries.py::symbol_detail`）。新曲线按周期取。两者并存时，曲线一的标题或注释里要写明「本周期 {日期} 冻结」，免得用户以为和那张卡是同一个冻结。

## 3. 每条曲线画什么

- **横轴**：价位。范围至少覆盖该分布的 Q02–Q98，并且一定包含成本价和当日收盘。
- **实线：到期概率**。价位 K 在起点价 S0（见下）之上时取 `P(S_T ≥ K) = 1 − CDF(K)`，在 S0 之下时取 `P(S_T ≤ K) = CDF(K)`。两段在 S0 处交汇。
- **阴影带：触及概率的无模型区间**（用户选定此方案，没用 2× 法则、BS 闭式解或历史实测）：
  - 下沿 = 到期概率（到期时收在 K 之外，路上必然经过 K）
  - 上沿，K > S0：`min over y<K of C(y)/(K−y)`，其中 `C(y) = ∫_y^∞ (1 − F(s)) ds`，即由 RND 算出的不贴现看涨期权价
  - 上沿，K < S0：`min over y>K of P(y)/(y−K)`，其中 `P(y) = ∫_{−∞}^y F(s) ds`，即不贴现看跌期权价
  - 结果截在 [下沿, 1] 之间
  - 依据：Brown–Hobson–Rogers (2001) *Robust hedging of barrier options* 的超复制论证。花 C(y)/(K−y) 买入 1/(K−y) 份行权价 y 的看涨期权，一旦价格触及 K，就按 K 卖空 1/(K−y) 份标的。只要触及过 K，这个组合至少收回 1。这个上界可以取到，所以不加额外假设就无法再压低。该区间对**盘中触及**和**收盘触及**都成立。
- **起点价 S0** = 该分布所在日期的 `forward`。区间论证要求价格过程是鞅，也就是取远期价。**概率方向按 S0 判断，盈亏正负按锚点判断**。深套仓位的这两者会分开，例如成本 100、现价 70 的多头：70 到 100 之间的价位属于「往上触及」，但在那里卖出仍然亏钱，也就是减亏区。横轴用底色区分盈区和亏区，以锚点为界。空头（qty < 0）直接套用同一套公式。
- **标记线**：成本价、当日收盘。曲线一另加本周期起点价，以及该冻结分布的 Q25、Q05（投机线和信念线，用细线，视觉上压低）。
- **悬停提示**：价位、相对锚点的百分比、到期概率、触及区间 [下, 上]、锁定金额（按全仓计）。

## 4. 必须显示的说明（去谜语化，一两句白话即可）

- 这是**风险中性定价**，不是历史上实际发生的频率。PIT 实测显示期权市场一贯低估上涨，MU、SNDK 上尤其明显。用一句话指向标的页已有的「PIT 校准」卡即可，**本页不做 PIT 校正**。
- 曲线只管到 {到期日}（DTE n），持有期不同就不能直接套用。
- 分布所在日的闸门 FAIL 时照样画，但要醒目标注，做法和现有页面处理闸门 FAIL 的方式保持一致。

## 5. 不做（YAGNI，用户明确说「有且仅有这两条曲线」）

- 不标最优点，不给建议价位，不做 PIT 校正，不画 2× 或 BS 单线，不加第三条曲线
- 不接币安实时价（RND 没有这个数据源）

## 6. 实现

### 6.1 后端

- 纯函数模块 `rnd/exit_curves.py`：输入 CDF 网格、起点价、锚点、仓位与价位数组，输出到期概率、触及上沿、锁定金额。积分在网格上用梯形法。无 IO，便于单测。
- 查询层 `server/queries.py`：从 `rnd_curve.grid_json`（strikes/cdf）、`rnd_indicators`（pinned、expiry、dte、forward、gate_pass、q05/q25）、`raw_chain.underlying_close`、`holdings_sync.entry_dates()` 装配。
- 接口（都要求鉴权）：
  - `GET /api/exit-curves`：侧栏列表，列出有 RND 覆盖的币安持仓，以及池内其他标的（其他标的只有曲线二）
  - `GET /api/symbol/{symbol}/exit-curves`：单个标的的两条曲线

### 6.2 前端

侧栏新增视图「止盈止损」，与「今日」「标的」「研究助手」并列。侧栏列出当前有币安持仓且有 RND 覆盖的标的，点选后展示两条曲线。没有持仓的标的只能画曲线二。沿用现有 `style.css` 的设计语言。

### 6.3 实现时自定的细节（规格未写，实现者按下列口径定）

1. **周期冻结日**取 `max(本周期第一天, entry_dates().rnd_date)`；`rnd_date` 为空（开仓早于数据）时取本周期第一天。本周期第一天 = 当前 pinned expiry 的最早 pinned 日期。
2. **CDF 数值清理**：先截到 [0, 1]，再取累计最大值，把数值噪声造成的微小非单调修平。线上 QQQ 2026-09-24 该行没有非单调点，验收数字不受影响。
3. **网格边界**：y 的候选取网格点。网格以外视为没有概率质量（C、P 在网格端点处为 0），所以网格外的价位两个概率都是 0。界面上把网格外的价位和外推区（`fit_meta.x_quoted_range` 之外）一样用灰底标出，注明「外推 / 网格外，不可信」。
4. **两条曲线共用同一个价位轴**：取两个分布 Q02–Q98 的并集，再并入成本价和当日收盘，两端各留少量余量，均匀取点。两张图上下对齐，方便对比。
5. `K == S0` 归入上方分支。
6. **没有持仓的标的**：`qty` 为空，不算锁定金额，不画盈亏底色，悬停只显示相对收盘的百分比。
7. Q25 / Q05 标记线按规格照画，不随多空方向改换分位。
8. **DTE 显示**：曲线一同时给出冻结时的 DTE 和今天剩余的 DTE；曲线二给今天的 DTE。
9. 前端路由为 `/exits/{symbol}`。

## 7. 测试（`tests/test_exit_curves.py`，合成数据，无网络）

1. 上沿 ≥ 下沿，且上沿 ≤ 1
2. 离 S0 越远，两者都单调下降
3. 在合成的对数正态分布（零漂移）上，BS 首达概率必须落在 [下沿, 上沿] 之内。BS 是与该终值分布一致的一种模型，落不进去就说明实现错了
4. 上方和下方的实现对称
5. 空头仓位的盈亏符号正确
