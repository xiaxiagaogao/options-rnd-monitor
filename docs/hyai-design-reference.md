# HYAI（hyskj.cn）产品考察笔记 — 仪表盘设计参考

> 2026-07-16 实地考察（登录态）。用途：RND 仪表盘（spec §8.5）前端设计参照。
> 定位差异先记牢：HYAI 是国内期货/期权、面向订阅用户的商业产品、日内实时；
> 我们是美股期权 RND、单用户自用、EOD。抄版面与交互，不抄指标观与商业化结构。

## 1. 信息架构总览

- **产品面只有两个一级入口**：AI 对话（首页即聊天）+ GEX 透镜（唯一的传统仪表盘页）。
  其余"产品"（波动率实验室 / 价差全景 / 研究会话）全是**对话模板入口**——卡片点击
  = 自动发送一条结构化提问。产品功能被收敛进 LLM 会话，页面数量极少。
- 环境组件：全市场热力图（弹层）、末日透镜小组件（侧栏常驻）、雷达小兽（主动推送气泡）。
- 未登录落地页与登录后完全两套皮：营销页深色酷炫（WebGL 流体主视觉 + 衬线大标题 +
  青/琥珀强调色），产品页浅色米绿系、信息密度优先。支持主题切换。[hyskj.cn].png

## 2. 值得抄的模式（按我们的三层 + 底座归位）

### 罗盘层（持仓诊断）可借鉴
- **一行式状态摘要条**（GEX 透镜顶部）："休市中 · 以下为 07-16 收盘数据 · 做市商正
  gamma(净+1.53Bn) · 现价距翻转位 +1.68% · Call 墙 7800 / Put 墙 7900 · ATM IV 65.8%
  日内 −8.0pt"。一句话把世界状态讲完，数据新鲜度声明打头。
  → 我们版本："2026-07-15 收盘 · SPY 钉 8/21 (DTE 37) · F 761.2 · ±1σ ±4.9% ·
  闸门 PASS · 距冻结 Q25 +0.8σ"。
- **右侧"关键位"数值卡**：Major Call 墙 / Put 墙 / 翻转位 / 现价距翻转位%——纵向
  键值表，重要数字右对齐加色。→ 我们的 Q05–Q95 + F + 众数 就该这么排。
- **自选列表带状态徽章**：每个标的名旁一个小胶囊（正γ/准备中）。→ 我们放闸门状态
  或 pinned DTE。

### 雷达层可借鉴
- **信号卡片**（落地页机会雷达）：`标的 · 信号类型 | 98 分位 | 迷你进度条 | 强度徽章
  （强信号/突发）`。分位是他们全站的信号通用语言（热力图、机会雷达、推送文案全用）。
- **热力图双指标切换**：treemap（格子=持仓量），颜色可切 涨跌幅 / IV 分位；无期权品种
  置灰。图例条 低[青]→高[琥珀]。→ 我们标的少用不上 treemap，但"同一版面双指标切换"
  和"覆盖不到就置灰"直接适用。
- **雷达小兽主动推送**：气泡文案 = 一句事实 + 分位定位（"调仓幅度处近60日 100 分位"）
  + "点我去问→"深链进对话 + "历史统计·非预测"小字。把异动检测变成对话入口的闭环。

### 温度计层可借鉴
- LLM 报告里的读数上下文话术："当前 IV 46.7%，近 30 个交易日区间 [37.1%, 69.1%]，
  处于中位——刚从 6 月底的极端风暴区退潮"。水平 + 区间 + 位置 + 一句叙事，四件套。

### 底座层（质量与运维）可借鉴
- **事件流 ↔ 图上标记同源**："与图上标记·数据闹钟同一检测器·点击行在图中定位·仅事实
  描述"。事件字形：△触墙被拒 ×试探失败 ◆穿越翻转位。→ 我们的事件条带（roll/闸门/
  双峰）应同源驱动时序图标记与事件列表，点击互相定位。
- **数据新鲜度声明**永远在最显眼处（"休市中·以下为收盘数据"）。EOD 产品更需要。
- **方法论免责脚注**："GEX 为自研做市商持仓推断模型输出的敞口估计…模型为估计值,
  存在误差""事件标记为规则化数据描述(触及/穿越等几何事实),不构成任何信号或建议"。
  → 对应我们的 RN≠真实、外推区打标声明。

### LLM 分析输出格式（将来接 LLM 时的模板）
- 标题带数据口径日期："碳酸锂波动率实验室 · 2026-07-16 收盘全景"；"已深度思考·3656 字"。
- **"维度 | 读数 | 白话"三列表**：每个指标配一行大白话（"IV=天气预报，RV=实际下的雨"）。
- 公式 + "翻译："模式：`VRP = IV² − RV² = +0.1034，正值。翻译：期权价格里嵌入的
  波动预期，明显高于市场最近实际波动。`
- **内嵌纪律引用块**（blockquote）："历史统计·不代表未来·非预测。VRP 正值说的是 IV
  高于 RV 这一统计事实，不代表 IV 必然下行。"——解读铁律做成 UI 组件。
- 数据来源/样本量披露脚注："IV 底库自 2025-05 起约 14 个月，长历史分位样本有限；以当前
  读数与近期走势为主"——样本不足主动降级声明（同我们"样本<60 不显示分位"）。
- 图表组件卡：三点式微笑截面（25Δ put / ATM / 25Δ call）+ 指标磁贴（每贴带一行解读）。
- 结尾："还可以看"后续问题按钮 + token 用量与实收价格明细行。
- ASK 引导模式：不确定怎么问时先弹选项把问题结构化再分析。

## 3. 交互细节清单

- 到期切换 = dte 徽章芯片：`[全部到期] [0717 dte1] [0821 dte36] …`（末日到期配 🌑 图标）。
- 时间粒度两排：窗口 [今日 5日 20日 全部] × 粒度 [1分 5分 15分 K线 分时]。
- 主图叠加开关：IV [主图/副图/关]、叠加 [量/事件]。
- 当日回放：拖动条 + 5× 速度，"K 线·IV·MM 敞口同步演变"。
- 数据闹钟：条件模板一键芯片（+净 GEX 转负 / +上穿 Call 墙…），免费 2 个分钟级。
- 侧栏小组件（末日透镜）：标签页 全市场/单手/日/时，行 = 品种 + 数值 + 一行口径说明。
- 模型档位选择器：深度思考·Pro / 快答·Flash。

## 4. 明确不抄的

- GEX / Max Pain / 席位分析：数据（OI）不可得 + 非 RND 原生 + spec 已裁决。
- 实时/秒级/盘中语义：我们 EOD 锁定，仪表盘定位是"昨收后的世界地图"。
- 商业化结构（Pro 锁、订阅墙、token 计费）：单用户自用无此需求；但"付费墙切在
  哪"（延迟档位/历史纵深/二阶维度）佐证了历史纵深是最值钱的部分——我们的 252 日
  分位层与曲线库正是这块。
- 全市场几十品种的扫描面：我们 3+2 标的，用并排卡片即可，不需要 treemap 与搜索列表。

## 5. 对第 5 步（仪表盘）的落地建议（待布局设计时展开）

1. 单页应用 + 顶部标的切换（SPY/QQQ/NVDA 胶囊）+ 到期 dte 芯片，不做多级导航。
2. 页面骨架自上而下：状态摘要条 → 罗盘区（K线+扇形带+冻结线 / 关键位卡）→
   雷达区（分位面板 + ΔCDF + 事件灯）→ 温度计区 → 底座（事件条带贯穿 + 诊断抽屉）。
3. 每个指标磁贴标配：数值 + 252 日分位色带 + Δ箭头 + 一行白话解读（hover 或常驻）。
4. 事件检测器单一来源：图上标记、事件列表、（将来）提醒共用。
5. 所有图表脚注化数据口径与纪律声明；闸门失败 = 整卡置灰 + 点开诊断（smile 拟合图）。
6. LLM 接入留位（V1+）：分析输出模板照 §2 的格式抄；入口可以是"关于今天的状态问一句"。
